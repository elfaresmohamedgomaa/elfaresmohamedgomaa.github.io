## 📖 نظرة عامة

**منصة الفارس في الرياضيات** هي تطبيق ويب تعليمي متكامل مبني بالكامل بـ **HTML/CSS/JavaScript خام** (بدون أي إطار عمل Framework)، ومُصمم خصيصًا لخدمة المرحلتين الإعدادية والثانوية باللغة العربية. المنصة تشتغل كـ **Single Page Application** وتدعم العمل كتطبيق (PWA) قابل للتثبيت على الموبايل.

---

## 👨‍🎓 الجزء الأول: للطلاب

المنصة بتوفر للطالب تجربة تعليمية متكاملة من مكان واحد:

### 🔐 تسجيل الدخول
- دخول آمن بكود خاص وكلمة مرور لكل طالب
- حماية من محاولات الدخول المتكررة (Login Lockout) لمنع اختراق الحسابات
- رابط دخول سريع (Deep Link) لكل طالب لتسهيل الوصول

### 📝 نظام الامتحانات
- امتحانات إلكترونية تفاعلية لكل صف دراسي
- مؤقّت زمني تلقائي لكل امتحان مع عرض النتيجة فور الانتهاء
- تتبّع عدد المحاولات، وتحديد جدول زمني (متاح / غير متاح) لكل امتحان
- عرض النتائج والدرجات بشكل فوري ومنظم

### 🎥 المحتوى التعليمي
- مكتبة فيديوهات شرح منظمة حسب المرحلة (ابتدائي - إعدادي - ثانوي)
- صفحة مذكرات وملازم قابلة للتحميل
- قناة تليجرام مرتبطة لكل صف دراسي

### 🎡 عجلة الحظ (Lucky Wheel)
- عنصر تحفيزي تفاعلي بجوائز وتأثيرات صوتية ورسوم متحركة (Confetti)
- مصمم لتحفيز الطلاب والمحافظة على تفاعلهم مع المنصة

### 🔔 الإشعارات
- نظام إشعارات فورية (Push Notifications) لتنبيه الطلاب بالجديد
- شات بوت مدمج للرد على استفسارات الطلاب

### 📱 تجربة موبايل كاملة
- تصميم متجاوب 100% (Responsive)
- إمكانية تثبيت المنصة كتطبيق على الشاشة الرئيسية (PWA)

## 👨‍💻 الجزء الثاني: للمبرمجين

### 🏗️ البنية التقنية

المشروع مبني بفلسفة **"ملف واحد يكفي"** — كل الواجهة، المنطق، والتصميم داخل `index.html` واحد (~12,700 سطر)، بدون أي عملية Build أو تثبيت Dependencies، عشان يشتغل فورًا على أي استضافة ثابتة زي GitHub Pages.

```
📦 المشروع
 ┣ 📜 index.html      → الصفحة الرئيسية + كل المنطق (HTML/CSS/JS)
 ┗ 📜 sw.js            → Service Worker لدعم PWA والعمل Offline
```

### ⚙️ التقنيات المستخدمة

| التقنية | الاستخدام |
|---|---|
| **Vanilla JavaScript** | كل منطق التطبيق بدون أي Framework |
| **Firebase Realtime Database** | تخزين ومزامنة بيانات الطلاب والإشعارات لحظيًا |
| **Firebase Auth** | نظام المصادقة والدخول |
| **html5-qrcode** | مسح أكواد QR لتسجيل الحضور |
| **qrcodejs** | توليد أكواد QR الخاصة بكل طالب |
| **JSZip** | تصدير بيانات مضغوطة (بطاقات، سجلات) |
| **Service Worker** | دعم العمل كـ PWA قابل للتثبيت |
| **Web Audio API** | مؤثرات صوتية تفاعلية (نقر، فتح، إشعارات) |

### 🧩 أبرز الأنظمة البرمجية

- **نظام إدارة الطلاب**: توليد أكواد وكلمات مرور فريدة، منع تكرار الأسماء، وتتبع بيانات كل طالب
- **نظام الامتحانات**: استيراد أسئلة بالجملة (Bulk Import)، تحليل معادلات رياضية (LaTeX)، جدولة وحساب الدرجات تلقائيًا
- **لوحة تحكم الأدمن**: متابعة شاملة للطلاب، تتبع الحضور، تعديل جوائز العجلة، إدارة الإشعارات
- **نظام الحضور بـ QR**: مسح وتسجيل حضور الطلاب لحظيًا مع عرض سجلات الجلسات
- **البطاقات الذهبية**: توليد بطاقات هوية مرئية للطلاب (Canvas rendering)

### 🚀 التشغيل محليًا

cd elfaresmohamedgomaa1.github.io

# افتح index.html مباشرة أو استخدم سيرفر بسيط
python3 -m http.server 8000
